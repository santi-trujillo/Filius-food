# Imágenes de Productos - Postres

Coloca aquí las imágenes de los productos de postres.

## Formato recomendado:

- **Formato:** JPG o WebP
- **Dimensiones:** 600x400px (ratio 3:2)
- **Peso:** < 100KB por imagen

## Imágenes necesarias:

- brownie.jpg
- cheesecake.jpg
- tiramisu.jpg
- mousse.jpg
- tarta-limon.jpg
- profiteroles.jpg
- macarons.jpg
- tarta-manzana.jpg

Las imágenes se pueden reemplazar con fotografías reales de los productos.
